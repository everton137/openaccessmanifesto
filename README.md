Guerrilla Open Access Manifesto
===============================

> **This repository is archived and no longer maintained.**

The *Guerrilla Open Access Manifesto*, written by Aaron Swartz in July 2008, in several languages.

- **Website:** https://openaccess.eza.link
- **Source code:** https://gitlab.com/everton137/openaccessmanifesto

The translations were first hosted at [openaccessmanifesto.wordpress.com](https://openaccessmanifesto.wordpress.com), then briefly at openaccessmanifesto.netlify.app. They now live on a simple static site with no database, comments or tracking. It has 25 languages so far, including Arabic and Persian. Bulgarian will be added once the broken text encoding from the original post is fixed.

To report issues or add a translation, please use the [GitLab repository](https://gitlab.com/everton137/openaccessmanifesto).
